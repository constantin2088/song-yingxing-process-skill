# 可填写工作表

## 第1步
选一个明确产出和工艺边界，说明产品要求、单位、批次与实际操作环境。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
逐步记录原料、工具、能量、时间、操作条件与产出，把操作者口诀拆成可观察动作。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
画先后依赖与中间产物，注明哪些步骤可并行、哪些必须等待；流程图不省略返工和废弃分支。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
登记投入、合格产出、副产物、返工与损耗，核对单位和批次；不能用未知损耗填零。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
找瓶颈和关键质量点，用小规模安全试做验证变更，保留操作者经验和与文字不一致处。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
输出工艺卡、依赖图、缺失参数与复核方案；涉及专业工艺由合格人员确认，历史来源不充当合规证明。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

检查工序或能力依赖的缺项、自依赖和循环，返回可用的先后顺序；不自动确定实施优先级。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_dependencies.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
